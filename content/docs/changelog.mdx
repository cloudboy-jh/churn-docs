## Version 2.1.7 - November 23, 2025

### API Key Management Enhancement 🔑

This update adds transparency to API key management with age tracking, helping you maintain secure and up-to-date credentials.

#### New Features

- **API Key Age Tracking**: Visual display showing when keys were last updated
- **Human-Readable Timestamps**: Shows "just now", "5 minutes ago", "2 days ago", etc.
- **Automatic Recording**: Timestamps are saved automatically when keys are set or replaced
- **Legacy Support**: Gracefully handles older configurations showing "unknown" until updated

#### Technical Changes

- Extended `ChurnConfig` interface with `apiKeyTimestamps` field
- Enhanced `setApiKey()` method to record update timestamps automatically
- Added `getApiKeyTimestamp()` helper function in config.ts
- Implemented `formatKeyAge()` utility for human-friendly time formatting
- Uses ISO 8601 format for timestamp consistency
- ModelSelect UI enhanced with key age information display

#### Files Modified

- `src/config/config.ts` (API key timestamp tracking)
- `src/components/ModelSelect.tsx` (UI enhancements)
- `CHANGELOG.md` (updated documentation)
- `package.json` (version bump to 2.1.7)

## Version 2.1.6 - November 23, 2025

### Agent Handoff System 🤝

This release introduces seamless integration with AI coding agents, enabling smooth transitions from analysis to implementation.

#### New Features

##### 1. Agent Handoff System

- **Interactive Handoff Prompt**: "Launch agent now? Y/N/C" after export completion
- **Multi-Agent Support**: 
  - Claude Code
  - Cursor
  - Gemini CLI
  - Codex
- **Agent Availability Checking**: Verifies agent is installed before attempting launch
- **Configurable Context Formats**: 
  - Minimal (MD+JSON)
  - Comprehensive options

##### 2. Enhanced Export Command

New flags for `churn pass` command:
- `--to <agent>`: Specify target agent (claude-code, cursor, gemini, codex)
- `--format <type>`: Set context format (minimal, comprehensive)
- `--launch`: Auto-launch agent without interactive prompt

##### 3. Handoff Settings UI

- New interactive configuration component
- Persistent preference storage
- User-friendly agent selection

#### Technical Changes

**New Files:**
- `src/engine/handoff.ts` - Core handoff engine
- `src/components/HandoffSettings.tsx` - Interactive configuration UI

**Modified Files:**
- `src/components/ExportPanel.tsx` - Added handoff callback support
- `src/config/config.ts` - Extended with `HandoffConfig` type
- `src/App.tsx` - Added "handoff-settings" phase to state machine
- `package.json` - Version bump to 2.1.6
- `CHANGELOG.md` - Updated documentation

#### Developer Experience

- Type-safe agent selection with `AgentType` union type
- Agent adapters for building provider-specific CLI commands
- Removed emojis from handoff-related output for cleaner terminal display

#### Breaking Changes

None - fully backward compatible

## Version 2.1.1 - November 9, 2025

### Stage 4: Differential Analysis Integration 🚀

This update brings significant performance and cost optimizations to staged mode through intelligent differential analysis.

#### New Features

- **Smart Differential Analysis**: Analyzes only changed lines instead of entire files in staged mode
- **Automatic Mode Selection**: Evaluates whether diff analysis saves >500 tokens before switching modes
- **Graceful Fallback**: Falls back to comprehensive analysis if diffs exceed 100 items
- **Enhanced Token Estimation**: Optimized calculations for diff scenarios (~50 chars/line)

#### Performance Improvements

- **70-90% token reduction** in staged mode
- **Faster analysis** by focusing only on changes
- **Better cost efficiency** for daily development workflows

#### Technical Changes

- Updated `analyzeFile()` to accept mode parameter ("full" or "diff") and FileDiff object
- Enhanced `buildPrompt()` for specialized diff mode prompting
- Added `shouldUseDiffAnalysis()`, `getStagedDiff()`, and `getFileDiff()` functions
- Improved token estimation logic for differential scenarios

#### Files Modified

- `src/engine/analysis.ts` (+59 lines, -4 lines)
- `src/engine/prompts.ts` (extended for diff mode)
- `src/engine/differential.ts` (new utility functions)
- `CHANGELOG.md` (+43 lines)
- `package.json` (version bump to 2.1.1)

## Version 2.1.0 - November 8, 2025

### Major Improvements: Adaptive Analysis & Context Awareness 🎯

This release introduces intelligent, context-aware analysis with language-specific prompts and automatic framework detection.

#### New Features

##### 1. Adaptive Prompt System

- **Language-Specific Templates**: Specialized prompts for TypeScript/JavaScript, Python, Rust, and Go
- **Smart File Handling**: 
  - Config files receive minimal suggestions (0-2)
  - Test files get quality improvements without "add tests" suggestions
  - Source files receive full language-specific analysis

##### 2. Context Detection

- **Automatic Framework Detection**:
  - Frontend: React, Next.js, Vue, Angular
  - Backend: FastAPI, Django, Flask, Express
  - Tools: npm, yarn, bundlers, test frameworks
- **TypeScript Configuration Reading**: Understands strict mode and compiler settings
- **Context Hashing**: Smart cache invalidation based on project context

##### 3. Enhanced Caching

- Cache entries now track **prompt version** and **context hash**
- Backward compatible with existing cache
- Graceful degradation for older cache entries

#### Performance Improvements

- 30-50% token reduction through adaptive prompts
- Context detection overhead: less than 500ms, cached per session
- Better cache efficiency with context-aware invalidation

#### Technical Changes

**New Files:**
- `src/engine/prompts.ts` - Adaptive prompt system
- `src/engine/context.ts` - Framework and context detection
- `src/engine/grouping.ts` - File grouping infrastructure (future features)
- `src/engine/differential.ts` - Differential analysis foundation

**Modified Files:**
- `src/engine/analysis.ts` - Integrated adaptive prompts and context detection
- `src/components/RunConsole.tsx` (+39 lines) - Enhanced UI with cache hits, token tracking, cost estimates
- `package.json` - Version bump to 2.1.0
- `CHANGELOG.md` (+90 lines)

#### Developer Experience

- Real-time cache hit indicators
- Token usage and savings tracking
- Estimated cost calculations with savings
- Color-coded output (green for success, blue for info, yellow for warnings)

#### Breaking Changes

## Upgrade Guide

### From 2.1.6 to 2.1.7

No breaking changes. Simply update:

```bash
# Using npm
npm update -g churn-cli

# Using bun
bun update -g churn-cli

# Using yarn
yarn global upgrade churn-cli

# Using pnpm
pnpm update -g churn-cli
```

API key age tracking is automatically enabled. Existing keys will show "unknown" age until updated.

### From 2.1.1 to 2.1.6

No breaking changes. Simply update using the commands above.

New features:
- Agent handoff system is available via `churn pass` command with new flags
- Configure handoff preferences via the new HandoffSettings UI
- Legacy configurations work without modification

### From 2.1.0 to 2.1.1

No breaking changes. Simply update using the commands above.

The differential analysis feature is automatically enabled in staged mode.

### From 2.0.x to 2.1.x

No configuration changes required. New features are automatically enabled:

- Adaptive prompts will be used based on detected project context
- Differential analysis activates in staged mode
- Existing cache remains valid with graceful degradation
