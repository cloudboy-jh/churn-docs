## Full Analysis

Analyzes all files in your repository (excluding ignored patterns).

```bash
churn run
```

### When to use

- First-time analysis
- Pre-release quality checks
- Comprehensive code reviews
- Major refactoring projects

### Cost implications

Analyzes entire codebase, highest API usage

## Staged Analysis

Analyzes only files in your Git staging area with intelligent differential analysis.

```bash
churn run --staged
```

### Smart Differential Analysis (v2.1.1+)

Churn now intelligently uses **differential analysis** in staged mode, analyzing only the changed lines rather than entire files. This delivers significant performance improvements:

- **70-90% token reduction** compared to full file analysis
- **Automatic mode selection**: Churn evaluates whether diff analysis saves more than 500 tokens
- **Graceful fallback**: If diffs exceed 100 items, falls back to comprehensive analysis
- **Smart optimization**: Only changed code is analyzed, not entire files

### How it works

When you run staged analysis, Churn:

1. Detects all staged files in your Git repository
2. Calculates the diff for each file (what changed)
3. Evaluates if diff analysis will save tokens (>500 token threshold)
4. Uses diff mode for optimal files, full mode for others
5. Analyzes only the relevant changes

### When to use

- Daily development workflow
- Before commits
- Quick quality checks
- Cost-conscious analysis
- Incremental code reviews

### Benefits

- **80-90% cost savings** compared to full analysis
- **Faster analysis** by focusing only on changes
- **Higher quality suggestions** targeted at your modifications
- **Optimal for iterative development**

## File-Specific Analysis

Analyzes specific files or patterns.

```bash
churn run --files "src/components/**/*.tsx"
```

### When to use

- Targeting specific modules
- Reviewing changed files
- Analyzing new features
- Debugging specific areas

### Examples

```bash
# Analyze all TypeScript files
churn run --files "**/*.ts"

# Analyze specific directory
churn run --files "src/auth/**/*"

# Multiple patterns
churn run --files "src/components/**/*.tsx" --files "src/hooks/**/*.ts"
```

## Choosing the Right Mode

| Use Case | Recommended Mode | Cost Impact |
|----------|-----------------|-------------|
| Daily development | Staged | 10-20% of full |
| Pre-commit checks | Staged | 10-20% of full |
| Feature review | File-specific | 20-40% of full |
| Release prep | Full | 100% |
| Initial analysis | Full | 100% |
