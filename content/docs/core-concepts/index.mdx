Understanding these core concepts will help you get the most out of Churn.

## Overview

Churn is built on a few fundamental concepts that make it powerful and flexible:

- **Repository Detection**: Automatic Git repository awareness
- **Analysis Modes**: Different ways to analyze your code
- **Suggestion System**: How findings are categorized and prioritized
- **Reports & Exports**: Multiple output formats for different use cases
- **Local-First Architecture**: Privacy-focused design
- **Smart Caching**: Intelligent content-based caching

Explore each concept in detail using the navigation menu.
