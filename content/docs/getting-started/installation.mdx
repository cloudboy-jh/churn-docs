## Prerequisites

Before installing Churn, ensure you have:

- **Git**: For repository detection and analysis
- **Node.js or Bun**: Runtime for the CLI tool
  - Node.js 18+ or Bun 1.x recommended

## Installation Methods

### npm (Recommended)

```bash
npm install -g churn-cli
```

### Bun

```bash
bun install -g churn-cli
```

### pnpm

```bash
pnpm add -g churn-cli
```

### Yarn

```bash
yarn global add churn-cli
```

### From Source (Development)

For contributors or those who want the latest development version:

```bash
# Clone the repository
git clone https://github.com/cloudboyjh1/churn2.0.git
cd churn2.0

# Install dependencies
bun install

# Build and link globally
bun run build
bun link
```

## Verifying Installation

After installation, verify Churn is working:

```bash
churn --version
```

You should see output similar to:

```
churn v2.0.5
```

## Updating Churn

To update to the latest version:

### npm

### Bun

```bash

```

### pnpm


### Yarn


### pnpm


## Troubleshooting Installation

### Permission Errors

If you encounter permission errors during global installation:

**npm (using npx)**:
```bash
npx churn-cli
```

**Or fix permissions**:
```bash
sudo npm install -g churn-cli
```

### PATH Issues

If the `churn` command is not found after installation, ensure your global package directory is in your PATH:

**For npm**:
```bash
echo 'export PATH="$PATH:$(npm config get prefix)/bin"' >> ~/.bashrc
source ~/.bashrc
```

**For Bun**:
```bash
echo 'export PATH="$PATH:$HOME/.bun/bin"' >> ~/.bashrc
source ~/.bashrc
```

### Version Conflicts

If you have multiple versions installed, uninstall all versions and reinstall:

```bash
npm uninstall -g churn-cli
bun remove -g churn-cli
# Then reinstall with your preferred package manager
```
