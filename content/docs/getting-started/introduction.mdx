## What is Churn?

Churn is a local-first CLI tool that brings AI-powered code analysis directly to your terminal. It helps you identify bugs, refactor code, optimize performance, and improve code quality without sending your code to the cloud.

## Why Churn?

### Philosophy and Benefits

- **Local-First Architecture**: Your code never leaves your machine when using Ollama
- **Privacy-Focused**: No telemetry, no cloud backend, no account required
- **Zero Setup**: Works immediately in any Git repository
- **Intelligent & Context-Aware**: Adaptive prompts based on language, framework, and project structure
- **Cost-Effective**: Differential analysis + smart caching save up to 90% on API costs
- **Fast**: Parallel processing + optimized diff analysis provides 10x speedup
- **Accurate**: Framework detection delivers more relevant, targeted suggestions
- **Deterministic**: Same input produces same output

### Key Features Overview

1. **Multi-Provider AI Support**
   - Anthropic Claude (Sonnet, Opus, Haiku)
   - OpenAI GPT (GPT-5, GPT-5 Mini, Nano, Pro)
   - Google Gemini (2.5 Pro, Flash, Flash-Lite)
   - Ollama (local models for complete privacy)

2. **Intelligent Analysis** ✨ New in v2.1
   - **Adaptive Prompts**: Language-specific templates (TypeScript, Python, Rust, Go)
   - **Context Awareness**: Automatic framework detection (React, Next.js, Django, FastAPI)
   - **Differential Analysis**: 70-90% token reduction by analyzing only changes
   - **Smart Mode Selection**: Automatic optimization based on file changes

3. **Flexible Analysis Modes**
   - Full repository analysis
   - Staged files only with differential analysis (80-90% cost savings)
   - Specific file patterns
   - Smart fallback for optimal performance

4. **Interactive Review**
   - Navigate suggestions with keyboard shortcuts
   - Accept or reject changes
   - View detailed code diffs
   - Filter by category and severity
   - Real-time token usage and cost tracking

5. **Smart Caching**
   - Content-based hashing (SHA-256)
   - Context-aware cache invalidation
   - 70% cost savings on reruns
   - 30-day cache duration
   - Prompt version tracking

6. **Multiple Export Formats**
   - JSON for programmatic access
   - Markdown reports for sharing
   - Git patch files for applying changes

## Who Should Use Churn?

Churn is ideal for:

- **Individual Developers**: Daily code quality checks before commits
- **Development Teams**: Standardized code review workflows
- **Open Source Maintainers**: Automated quality checks on contributions
- **Security Teams**: Vulnerability and bug detection
- **Tech Debt Managers**: Identifying refactoring opportunities

## Quick Demo

```bash
# Install Churn globally
bun install -g churn-cli

# Navigate to your Git repository
cd your-project

# Select your AI provider
churn model

# Run analysis on staged files
churn run --staged

# Review suggestions interactively
churn review

# Export results
churn export
```
