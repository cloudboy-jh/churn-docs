## What Churn Does

Churn removes the mental load of cleanup and refactoring so you can move faster, stay consistent, and focus on building instead of maintenance.

It reviews your code, finds issues, and generates patches you can apply in seconds.

## Why Use It

- **Takes the boring parts off your plate** — Refactoring, cleanup, and code consistency checks happen automatically
- **Keeps your code consistent** — Even when jumping between projects or working late
- **Catches what you miss** — Finds issues you'd normally overlook when tired or moving fast
- **Turns cleanup into quick patches** — Big refactoring jobs become simple apply-and-done operations
- **Works with any model** — Claude, GPT, Gemini, or run locally with Ollama

## Quick Start

```bash
# Install
bun install -g churn-cli

# Go to your project
cd your-project

# Pick an AI model
churn model

# Analyze staged files
churn run --staged

# Review and apply suggestions
churn review

# Export if needed
churn export
```
