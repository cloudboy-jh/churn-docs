Run your first code analysis with Churn using the interactive TUI.

## Launch Churn

Navigate to any Git repository and start the interactive interface:

```bash
cd /path/to/your/project
churn start
```

The TUI guides you through everything—model selection, analysis, and reviewing suggestions.

## What You'll See

### 1. Model Selection

On first run, you'll be prompted to select an AI provider:

- **Anthropic Claude** (Recommended)
- **OpenAI GPT**
- **Google Gemini**
- **Ollama** (Local, free, private)

For daily development, we recommend **Claude Haiku** (fast and cost-effective) or **Ollama with deepseek-r1** (free, local, private).

For important releases, use **Claude Sonnet** or **Claude Opus** for maximum quality.

### 2. API Key Configuration

If using a cloud provider, you'll be prompted to enter your API key:

- **Anthropic**: Get your key at [console.anthropic.com](https://console.anthropic.com)
- **OpenAI**: Get your key at [platform.openai.com](https://platform.openai.com)
- **Google**: Get your key at [aistudio.google.com](https://aistudio.google.com)
- **Ollama**: No API key needed—just [install Ollama](/docs/ollama) first

### 3. Analysis Options

The TUI presents analysis options:

- **Staged files**: Analyze only files in your Git staging area
- **Full repository**: Scan your entire codebase
- **Specific files**: Select files or patterns to analyze

### 4. Review Suggestions

After analysis, navigate suggestions interactively:

| Key | Action |
|-----|--------|
| ↑/↓ | Navigate between suggestions |
| Enter | View details |
| A | Accept suggestion |
| R | Reject suggestion |
| Q | Quit |

Each suggestion shows:
- **Category**: refactor, bug, optimization, style, documentation
- **Severity**: low, medium, high
- **Description**: What the issue is
- **Recommendation**: How to fix it
- **Code Diff**: Before and after (when applicable)

### 5. Export Results

From the TUI, export your analysis in multiple formats:
- `.churn/patches/suggestions-*.json` — Full JSON report
- `.churn/patches/report-*.md` — Human-readable Markdown
- `.churn/patches/changes-*.patch` — Git patch file
