Churn is a powerful CLI tool that brings AI-powered code analysis directly to your terminal. Built with a local-first philosophy, it helps you refactor smarter without sending your code to the cloud.

## Key Features

- **AI-Powered Analysis**: Leverage Claude, GPT, Gemini, or local Ollama models
- **Local-First**: Your code never leaves your machine when using Ollama
- **Zero Setup**: Works immediately in any Git repository
- **Smart Caching**: 70% cost savings on reruns with content-based hashing
- **Multiple Modes**: Full, staged, or file-specific analysis
- **Interactive Review**: Navigate and apply suggestions with ease
- **Export Options**: JSON, Markdown, and Git patch formats

## Quick Start

```bash
# Install Churn
bun install -g churn-cli

# Run your first analysis
churn run

# Review suggestions
churn review

# Export results
churn export
```

## Why Churn?

- **Privacy**: Local-first architecture, no cloud dependencies
- **Cost-Effective**: Staged mode saves 80-90% on API costs
- **Fast**: Parallel processing with 10x speedup
- **Professional**: Quiet, focused, monospaced aesthetic
- **Open Source**: MIT licensed, community-driven
