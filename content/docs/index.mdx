Churn removes the mental load of cleanup and refactoring so you can move faster, stay consistent, and focus on building instead of maintenance.

## What You Can Do

- Run `churn start` to launch the interactive TUI
- Select your AI provider and analyze files in one place
- Review and apply suggestions interactively
- Use Claude, GPT, Gemini, or run locally with Ollama

## Quick Start

```bash
# Install
bun install -g churn-cli

# Go to your project and start the interactive TUI
cd your-project
churn start
```

That's it. The interactive interface guides you through model selection, analysis, and reviewing suggestions—all in one place.
