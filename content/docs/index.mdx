Churn removes the mental load of cleanup and refactoring so you can move faster, stay consistent, and focus on building instead of maintenance.

## What You Can Do

- Run `churn run --staged` to analyze files before committing
- Review suggestions interactively with `churn review`
- Apply fixes as patches or export reports for your team
- Use Claude, GPT, Gemini, or run locally with Ollama

## Quick Start

```bash
# Install
bun install -g churn-cli

# Analyze staged files
churn run --staged

# Review suggestions
churn review
```
